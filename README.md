# 分布式智能云存储与 RAG 知识库系统

基于 C++20 实现的企业级分布式云存储系统，扩展 RAG 智能文档助手功能，将传统云盘升级为企业级智能知识库。

## ✨ 核心特性

- **三层微服务架构**：无状态网关层 + 元数据层(RaftKV) + 存储层，支持独立水平扩展
- **动态服务发现**：基于 RaftKV Watch 机制实现秒级节点上下线感知，30秒健康检查兜底
- **一致性哈希**：160虚拟节点/物理节点，O(log n)查找复杂度，解决数据倾斜问题
- **企业级知识库**：Annoy 向量存储 + BM25 混合检索，基于 LLM 意图识别实现动态路由
- **流式问答**：SSE 流式响应，支持多轮流式智能问答
- **中文支持**：完整的 URL 编解码，支持中文文件名

## 🚀 快速开始

### 编译项目

```bash
mkdir -p build && cd build
cmake ..
make -j4
```

### 启动服务（按顺序）

```bash
# 1. 启动元数据节点（RaftKV）
./bin/meta_node 1 127.0.0.1 9000 1

# 2. 启动存储节点（可启动多个）
./bin/storage_node 1 8001 9000
./bin/storage_node 2 8002 9000

# 3. 启动网关
./bin/gateway 8080 9000
```

### 访问 Web 界面

打开浏览器访问：`http://localhost:8080`

## 🤖 RAG 知识库问答

### 工作流程

**1. 文件上传阶段（一次上传，全部落库）**
```
文件上传 → Chunk 切分 → 向量化 → BM25 索引 → LLM 生成摘要 → 落盘
```

**2. 用户提问阶段**
```
用户问题 → [网关] 拉取所有文件摘要 → LLM 意图识别 → 动态路由到目标节点
         → [存储节点] 向量+BM25 混合检索 → 返回 TopK 片段 → LLM 生成回答 → SSE 流式返回
```

## 🔄 动态节点管理

### 节点上线
1. 存储节点向 RaftKV 注册：`Put("NodePort:{nodeId}", "{port}")`
2. 元数据节点通过 Watch 机制推送上线通知给所有网关
3. 网关建立 RPC 连接并添加到一致性哈希环

### 节点下线
1. 存储节点优雅关闭：`Del("NodePort:{nodeId}")`
2. 元数据节点推送下线通知
3. 网关从一致性哈希环移除节点
4. **兜底**：网关30秒健康检查发现无响应节点主动移除
